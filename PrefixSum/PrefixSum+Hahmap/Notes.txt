PREFIX SUM + HASHMAP
====================

1. START FROM BRUTE FORCE
-------------------------

For a subarray:

[start ........ end]

we want:

sum(start...end) = k

Brute force checks different start and end positions.

The problem:
Many start/end combinations -> O(n^2)


2. PREFIX SUM
-------------

For:

nums = [1, 2, 3, 4, 5]

prefix:

index:   0   1   2   3   4
nums:    1   2   3   4   5
prefix:  1   3   6  10  15


3. SUBARRAY SUM USING PREFIX SUM
--------------------------------

For:

[start ........ end]

sum(start...end)
=
prefix[end] - prefix[start-1]


Example:

nums = [1,2,3,4,5]
k = 7

        start   end
          ↓      ↓
[1, 2, |3, 4|, 5]

prefix[end] = prefix[3] = 10
prefix[start-1] = prefix[1] = 3

10 - 3 = 7


4. DERIVE THE HASHMAP CONDITION
-------------------------------

We want:

prefix[end] - prefix[start-1] = k

Rearrange:

prefix[start-1] = prefix[end] - k


Therefore:

required previous prefix
=
current prefix - k


5. WHY HASHMAP?
---------------

At every current position:

currentSum = prefix[end]

We need to find:

currentSum - k

among previously seen prefix sums.

Instead of searching all previous prefix sums,
store them in a HashMap.


Process:

currentSum += nums[i]

required = currentSum - k

check required in HashMap

if required exists:
    valid subarray(s) exist

then store currentSum


6. COUNTING SUBARRAYS
---------------------

For counting:

mp[0] = 1

currentSum += nums[i]

count += mp[currentSum - k]

mp[currentSum]++


7. WHY mp[0] = 1?
------------------

It represents the prefix sum 0 before the array starts.

Example:

nums = [7]
k = 7

currentSum = 7

currentSum - k = 0

Since mp[0] = 1:

one valid subarray exists:

[7]


8. WHY STORE FREQUENCY?
-----------------------

Suppose:

mp[5] = 3

This means prefix sum 5 appeared 3 times.

If:

currentSum - k = 5

then there are 3 possible previous positions.

Therefore:

count += mp[currentSum-k]


9. IMPORTANT ORDER
------------------

Correct:

currentSum += nums[i]

count += mp[currentSum-k]

mp[currentSum]++


Check first.
Store current prefix after checking.


10. CORE MENTAL MODEL
---------------------

[start ........ end]

prefix[end] - prefix[start-1] = k

prefix[start-1] = prefix[end] - k

currentSum - k

        ↓

search previous prefix in HashMap

        ↓

found?

        ↓

YES -> valid subarray


11. RECOGNITION
---------------

When you see:

subarray
+
sum = K
+
negative numbers may exist

Think:

Prefix Sum + HashMap


12. COMPLEXITY
--------------

Time:  O(n)

Space: O(n)
